## Purpose

This review checks whether another contributor can understand and follow the tutorial maintenance instructions without needing help from the original documentation author.

The reviewer should use the [Contributor Guide](contributor-guide.md) and attempt to follow the process for updating one tutorial step.

## Review Request

The reviewer has been asked to:

1. Read the contributor guide.
2. Follow the instructions for updating one tutorial step as far as possible.
3. Check whether the repository locations, step registry, stable-target rules, version rules and testing instructions are understandable.
4. Report any missing or unclear instruction.
5. Record where the process becomes blocked if the required implementation is unavailable.

The reviewer does not need to change or merge production code.
