# First-Time OnTrack Tutorial Documentation

This folder contains the student and contributor documentation for the First-Time OnTrack Tutorial.

The tutorial is designed to help new students become familiar with the main parts of OnTrack. It covers selecting a unit, finding the project or task dashboard, understanding the target grade and locating the calendar.

## Documentation

* [Student Guide](student-guide.md) – Explains what the tutorial teaches and how to start, skip, finish and replay it.
* [Troubleshooting Guide](troubleshooting.md) – Provides help when a unit, tutorial feature or target is unavailable, or when progress cannot be saved.
* [Contributor Guide](contributor-guide.md) – Explains how the tutorial is structured and how contributors can update it safely.
* [Evidence Index](evidence-index.md) – Records the tickets, branches, pull requests, test results and other evidence connected to TUT-D04.
* [Project Handover](handover.md) – Summarises the current project status, health, risks, limitations and next steps.

## Current Status

The written documentation structure is complete, but the guides are still drafts. Some tutorial implementation, testing, security review and pilot tasks are unfinished.

The documents must be checked again after the interface becomes stable. Final screenshots, walkthrough evidence, test results, pull request links and the second-contributor review will then be added.

## Privacy

Any screenshots, recordings or testing evidence used for this documentation must use demo or synthetic data.

Do not include real student names, identification numbers, marks, submissions, feedback, extensions, disability information or unit-performance data.
