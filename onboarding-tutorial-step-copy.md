# DOC-11: Onboarding Tutorial Step Copy

**Ticket:** DOC-11

**Author:** Jeffy Sam Babu

**Last updated:** 18 September 2026

## Purpose

This document provides the proposed wording for the first four steps of the OnTrack onboarding tutorial. The steps are based on the student needs recorded in DOC-9.

The wording is kept short so that students can understand each feature without having to read a large amount of text.

## Confirmed Tutorial Steps

The four highlighted areas are:

1. Unit selection
2. Task dashboard
3. Target grade
4. Calendar options

The first-login user story is covered by the tutorial opening. Skipping and replaying the tutorial are covered by the supporting messages below.

## Tutorial Opening

**Title:** Welcome to OnTrack

**Message:** Take a quick tour of the main areas you will use to find your unit, tasks, target grade and calendar.

**Button:** Start tutorial

## Step Copy

### Step 1: Choose Your Unit

Use the unit selector to open the unit you want to work on.

### Step 2: Find Your Tasks

This dashboard shows the tasks for your selected unit and the progress you have made.

### Step 3: Check Your Target Grade

Your target grade shows the result you are working towards, and you can change it here if needed.

### Step 4: Use the Calendar

Open the calendar options to download or subscribe to important unit dates.

## Skip Prompt

**Title:** Skip for now?

**Message:** Not ready to continue? You can skip the tutorial and start it again later.

**Buttons:** Continue tutorial / Skip for now

## Confirm-Skip Prompt

**Title:** Skip the tutorial?

**Message:** Are you sure you want to skip? You can start the tutorial again later if you need it.

**Buttons:** Go back / Skip tutorial

## Completion Message

**Title:** Tutorial complete

**Message:** You are ready to get started with OnTrack. You can replay the tutorial later if you need a reminder.

**Button:** Finish

## Tone and Review Notes

The wording uses short sentences, familiar terms and one clear action per step. It avoids technical language and does not assume that the student already understands the OnTrack interface.

The exact replay location is not named because it has not yet been confirmed. Button labels and highlighted interface targets should be checked during implementation review.
