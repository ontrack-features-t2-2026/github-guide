# Onboarding Tutorial Problem Statement and User Stories

**Ticket:** DOC-9
**Author:** Jeffy Sam Babu
**Last updated:** 16 September 2026

## Evidence Used

The Planner ticket states that roughly one-third of feedback respondents identified homepage navigation and finding information as a difficulty.

The original feedback responses were not attached to DOC-9, so this document uses only the confirmed summary provided in the ticket. It does not make assumptions about comments that were not available for review.

## Problem Statement

Some students have difficulty knowing where to begin when they first use OnTrack. Common actions such as selecting a unit, finding the task dashboard, checking or changing a target grade and locating calendar options may not be immediately clear.

When students cannot find these areas, they may spend unnecessary time searching or depend on someone else to explain the interface. A short and optional onboarding tutorial would give students a clear starting point while still allowing experienced users to skip it and return to it later if needed.

## User Stories

### 1. First Login

As a student using OnTrack for the first time, I want a short introduction to the main areas of the site so that I know where to begin.

### 2. Selecting a Unit

As a student enrolled in multiple units, I want the tutorial to show me how to select the unit I need so that I can access the correct tasks and information.

### 3. Finding Tasks

As a student, I want to know where to find the project or task dashboard so that I can quickly see the work I need to complete.

### 4. Target Grade

As a student, I want to understand where my target grade is displayed and how it can be changed so that I can plan my work around my intended result.

### 5. Calendar

As a student, I want to know where to find and download or subscribe to the OnTrack calendar so that I can keep track of important task dates.

### 6. Skipping and Replaying the Tutorial

As a student who may not need the tutorial immediately, I want to skip it and replay it later so that I can view the guidance when it is useful to me.

## Scope

This document defines the navigation problem and the main student needs behind the onboarding tutorial. It does not design or implement the tutorial, change production code or define unrelated staff onboarding requirements.

Detailed behaviour, accessibility requirements, privacy limits and implementation decisions remain within their relevant tutorial tickets.
